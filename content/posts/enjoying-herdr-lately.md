I've been using [herdr](https://herdr.dev/) for a few weeks now and I really like it. I haven't explored a lot of plugins yet. The ones I tried never worked and I was too busy to tinker with them. 

But two main features that still has me using it:

1. AI agent integration - getting different notifications based on inputs needed or completion notification 
2. Keeping everything organized with workspaces. 

There are a few key bindings I need to configure that'll make my life easier. But so far so good.
