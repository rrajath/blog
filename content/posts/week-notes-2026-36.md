Last week was productive for app development. Here are some highlights.  

## Grove

I announced my app, [Grove](https://github.com/rrajath/grove), on Reddit and it was well received. I got so many people eager to test the app and saying they have been looking for something like this. It was nice to see users actually wanting it. I got a lot of feature requests and bug reports. I addressed most of them and made a few releases. I signed up to publish the app on Play Store which required me to run a closed testing phase for 2 weeks with at least 12 testers. It's been a week since I started that and the responses have been great. I'm adding more features and will be making a few more releases for the next couple of weeks. 

Before the announcement is also when I noticed someone had made a feature request a couple of weeks ago for adding support for subfolders. I had missed this completely because I never looked at the issues tab on GitHub. And I never talked about the app anywhere. So, I was building it for myself. 

I probably need to change the name of the app since there was a [package that was recently created with the same name](https://jonathanchu.is/posts/introducing-grove/), but for a different purpose. 

## Expander

I saw the GitHub repo for [Expander](https://github.com/rrajath/expander) after a long time and found that there were 4 issues opened, with the first issue dating back to Apr 29. Since GitHub didn't notify me of new issues created in the repo and I never bothered checking the Issues tab. 

But seems like people have been using it. I was only seeing the repo being started every now and then. It was also nice to see someone responding to the feature requests and questions on my behalf with accurate and helpful explanations. There was one report of the app being blocked by Play Services since it was side loaded. It also contained accessibility service that reads user provided inputs in text fields. I ended up getting the app verified and also submitting an appeal to Play Store explaining the use case and the rationale behind the accessibility service usage.
